# Key Generator Utility

Максимально простая утилита для генерации пары ключей (private/public) с фиксированными именами файлов.
Не принимает аргументов командной строки. Ключи создаются в текущей рабочей директории.
В первую очередь утилита создана для сихнронизации параметров при генерации и использованиие ключей (MLKEM768-X25519)

## Важно

Утилита не управляет инфраструктурой. Перед запуском убедитесь, что:

1. **Права на запись в директорию**
   - Процесс должен иметь право создавать файлы в текущей рабочей директории. Рядом с исполняемым файлом

2. **Свободное место на диске**
   - Ключи маленькие, но убедитесь, что на разделе есть хотя бы несколько мегабайт свободного пространства.

3. **Перемещение ключей**
   - Разработчик обязан самостоятельно переместить `private.key` и `public.key` (или файлы с выбранными именами) в директорию, откуда их читает основное приложение.

4. **Защита приватного ключа**
   - Разработчик обязан самостоятельно позаботится о защите приватного ключа

5. **Повторный запуск**
   - Утилита **перезаписывает** существующие файлы с теми же именами без предупреждения.
